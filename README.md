# 琅嬛

面向长篇小说的 Android AI 创作 App。核心不是“一键续写”，而是通过小说圣经、三级大纲、结构化长期记忆和一致性审查，让几十万字长篇仍尽量沿着既定故事轨道生长。

- 当前版本：`0.3.0-alpha01`
- 作者：惜故里丶

## 当前里程碑

- 原生 Android + Kotlin + Jetpack Compose
- 书架、创作台、长期记忆、AI 设置四个主页面
- 与「洛书」同源的 MIUIX / HyperOS 视觉：Monet 动态色、Haze 模糊、Miuix Blur 液态玻璃和 Miuix Squircle
- 小说、三级大纲、人物状态、时间线、伏笔、章节草稿等核心领域模型
- Room 本地数据库：小说状态、章节版本、AI 配置、长期记忆索引持久化
- 章节通过一致性检查后才允许写入数据库，并同步更新人物状态和章节记忆
- 轻量相关记忆检索：生成前从圣经、人物、时间线、伏笔、历史章节中筛选相关上下文
- 多 AI 配置管理：可以保存多个中转站/官方 API，独立选择模型并切换当前服务
- API Key 使用 Android Keystore + AES/GCM 加密，Room 中不保存明文密钥
- AI 中转站自动识别：OpenAI 兼容（含 DeepSeek）、Anthropic Claude、Gemini、Azure OpenAI、Ollama
- 自动拉取模型列表、识别推理/视觉模型；中转站未开放列表时支持手填模型名
- 防跑题提示词组装器与本地一致性门禁

## 防跑题链路

1. 读取被锁定的小说圣经和全局硬约束。
2. 读取总纲、卷纲、章纲，并确定当前章必须完成的目标。
3. 从 Room 长期记忆索引检索当前章节最相关的设定、人物状态、时间线、伏笔和历史摘要。
4. 先生成结构化章节计划，再生成正文。
5. 对正文执行一致性检查；存在严重冲突时禁止入库。
6. 通过检查后保存章节新版本，同时更新人物状态、章节摘要和长期记忆索引。

## AI 配置

AI 设置页允许同时保存多个服务。每个服务独立保存 API 地址、协议、模型和参数；API Key 只进入 Android Keystore 加密区。点击已保存服务即可切换当前生成模型，也可单独编辑或删除。

## 打开方式

使用较新的 Android Studio 打开项目目录并等待 Gradle 同步。项目使用 JDK 17、minSdk 28、targetSdk 36、compileSdk 37。

仓库已配置 GitHub Actions。每次推送到 `main` 都会执行 Debug 构建，并上传 APK 构建产物。
