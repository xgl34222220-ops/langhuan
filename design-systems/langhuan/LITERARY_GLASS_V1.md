# 琅嬛 Literary MIUIx / Langhuan Glass V1

> 这是琅嬛 UI 重构的视觉与交互基线。后续页面迁移优先复用语义 Token 和共享组件，不再为每个页面单独发明一套样式。

## 1. 产品气质

琅嬛不是“AI 工具面板套小说功能”，而是一款以阅读和作品为中心的小说 App：

- 表层保持安静、文学、可阅读。
- AI、Skill、Agent、记忆和运行状态在用户需要时自然展开。
- 阅读与创作共用同一作品模型，但阅读器本身保持 content-first。
- 不用大量开关、边框、Dashboard 卡片暴露内部复杂度。

## 2. 核心视觉

### 浅色

- Background / 暖纸：`#E8E5DF`
- Surface / 主表面：`#F4F1EA`
- Foreground / 主文本：`#292724`
- Muted / 次文本：`#77736D`
- Primary / 琥珀：`#B47A32`
- Accent / 淡青：`#C6D9DC`
- Track / 分隔：`#D6D1C9`

### 深色

- Background：`#171613`
- Surface：`#201E1A`
- Primary：`#D9A968`
- Accent：`#354F52`

默认关闭 Android Dynamic Color，保留后续外观设置入口。琅嬛的品牌色不应因 ROM / 壁纸变化而失去一致性。

## 3. 字体层级

UI 使用 Inter Tight 的紧凑节奏；Android 端当前使用 SansSerif fallback 保证中文覆盖。小说正文与章节标题独立使用文学衬线体系，不受 App UI Typography 影响。

- 页面标题：22 / 28sp，SemiBold，-0.7sp
- 章节级 UI 标题：19 / 24sp，SemiBold，+0.6sp
- 正文 / 日期 / 状态：14.5 / 18sp，Regular，+0.3sp

## 4. 深度，而不是边框

- 卡片圆角：12 / 15 / 18dp 按深度变化。
- 浮动大容器可使用 24dp。
- 卡片层级用柔和 `shadow + surface + inset highlight` 表达。
- 不用可见描边建立层级。
- 中性分隔线只使用 1px `track`。
- 圆形按钮 38–46dp，使用柔和投影和内嵌高光，不用死板平面填充。

## 5. 主导航

底部固定为四个产品级入口：

1. 首页
2. 书库
3. 创作
4. 我的

“创作”不是把所有工具摆出来，而是进入 AI 建书、导入、创作能力和运行状态的渐进式入口。

## 6. 页面架构

### 首页

- 问候与琅嬛品牌头部
- 继续阅读 / 继续创作
- 快速开始：AI 建书、导入小说
- 最近作品
- 后续加入 AI 创作动态、伏笔/角色状态摘要

### 书库

- 同时承载阅读书籍与自己的创作作品
- 搜索优先
- 卡片显示书名、类型、当前章节/进度
- 长按进入阅读、故事模式、管理操作
- 后续加入“全部 / 我的作品 / 阅读 / 已完结 / 最近”筛选

### 创作

- 默认突出“和 AI 一起建一本书”
- 用户用正常聊天表达要求
- Skill / Agent / Tool 自动路由，能力管理属于二级入口
- 不把建书流程重新做成复杂表单

### 我的 / 设置

设置使用分组卡片和状态摘要：

- AI 与模型
- 创作与记忆
- 阅读
- 外观
- 数据与备份
- 关于琅嬛

只让真实可用的目的地可点击。没有接入业务的项目先显示状态摘要，不放假开关。

### 作品工作台（下一阶段）

一本“自己的作品”进入后展开：

- 正文
- 故事：总纲 / 卷纲 / 章纲 / 时间线 / 伏笔
- 世界：世界观 / 地点 / 规则 / 势力
- 角色：角色卡 / 关系 / 状态 / 弧光
- AI：可读取整本项目上下文的正常对话

### 阅读器（下一阶段）

- 默认只有正文，Chrome 自动退场
- 点击屏幕中央才出现顶部和底部控制
- 阅读操作保持少而明确
- 选中文本后可扩展“问琅嬛”，但不能污染常驻阅读 Chrome

## 7. 迁移原则

1. 数据库启动保护、阅读分页、AI Gateway、写作引擎不因 UI 重构而改动。
2. 新 UI 优先复用现有 ViewModel / callback，不复制业务逻辑。
3. 旧页面在迁移期间保留为 fallback，验证完成后再清理。
4. 每批迁移必须通过现有 Android CI 与 contract tests。
5. CI 通过不等于视觉验收完成；真机交互、滚动、键盘、暗色和大字体仍需单独检查。
