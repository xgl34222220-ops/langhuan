# 琅嬛 · 清墨交互逆向契约

> 来源：用户提供的 82.6s 真机录屏 + `base(4).apk` 静态资源结构。
> 目标：只复刻可观察到的界面结构、交互、动效节奏和功能行为；代码使用 Jetpack Compose 独立实现，不复制原 App 的 Dart/Flutter 代码、品牌素材或专有资源。

## 1. 已确认技术信息

- 目标 APK 为 Flutter 应用：包含 `libflutter.so`、`libapp.so`、`assets/flutter_assets`。
- APK 资源暴露了完整阅读器能力簇：主题、字体、字号、行距、首行缩进、亮度、上下翻页、仿真翻页、全文搜索、音量键翻页、屏幕常亮、时间电量、沉浸式、点击动画、下拉书签、全屏下一页、背景图遮罩、背景跟随、状态栏、导航栏、锁定竖屏、听书、书源、净化、缓存等。
- 不使用 APK 内 SVG/PNG 作为琅嬛资源；仅将资源命名用于功能存在性确认。

## 2. 书架

### 布局
- 全屏纯白/近白画布，内容从状态栏下方开始。
- 顶部左侧标题 `正在阅读`，右侧仅两个图标：`+`、用户。
- 书籍固定三列；无卡片、无阴影、无标签、无章节/字数信息。
- 封面为窄长竖版，几乎直角；书名位于封面下方，居中，最多两行。
- 网格横向留白明显大于封面内部留白，行间距约为标题高度的 2.2–2.6 倍。

### 交互
- 点击封面：进入阅读器。
- 长按封面：进入书籍管理动作（琅嬛保留编辑书名/封面/简介、进入故事、删除）。
- `+`：进入添加/导入流程。
- 用户图标：进入独立个人中心页面，不使用 BottomSheet。

## 3. 阅读页

### 正文表面
- 暖米黄色阅读背景，近黑正文。
- 顶部显示极弱章节名；右上可出现淡竹叶/纹理装饰，但琅嬛使用自有装饰。
- 正文为高行距、大字、首行缩进；底部弱化时间/电量/页码。
- 左/右点击用于翻页，中间点击唤起控制层。

### 控制层
- 控制层不是传统 AppBar + Toolbar，而是底部可变高度白色面板。
- 面板顶部有短灰色拖拽条。
- 底部固定三段：`详情 / 目录 / 更多`。
- 切换 tab 时面板高度随内容变化；正文保持可见，不加大面积黑色遮罩。

### 目录 tab
- 顶部：返回、书名、书签、夜间模式。
- 显示卷/书名与当前章节列表；当前章节使用蓝色强调。
- 右侧有细蓝色章节滚动指示条。

- 文案为浅灰，圆底直径约 48–52dp。

## 4. 主题页

- 从阅读器进入独立全屏页面。
- 顶部返回；标题区为 `日间主题 / 夜间主题` 双 tab；右侧搜索/帮助/新增入口。
- 主题使用双列卡片瀑布/网格；卡片本身展示背景色和简单几何纹理。
- 未安装主题显示彩色 `下载` 胶囊按钮；当前主题显示勾选状态。
- 主题选择立即返回/应用到阅读页，不破坏当前阅读锚点。

## 5. 书架管理 / 新建书架

录屏确认存在：
- `书架列表` 页面：复选框、正在阅读分组、横向封面预览、更多按钮。
- `新建书架` 页面：书架名称、布局（网格/列表）、便捷开关、排序选项、保存按钮。
- 键盘出现时页面保持原生滚动与底部安全区。

琅嬛对应实现：作为本地书架分组，不接入对方账户或云端。

## 6. 个人中心

- 独立全屏白色页面。
- 顶部返回；头像、昵称、编辑入口。
- 主列表：签到、探索、阅历、勋章、锦书、读过、同步、设置。
- 点击账户区域进入独立登录页；琅嬛只实现自己的本地/未来账户入口，不连接目标 App 服务。

## 7. 动效反推

从 73.79fps 录屏逐帧估算：

- 阅读底部面板进入：约 160–220ms，Y 轴自下而上，弱 fade；无弹簧回弹。
- 面板 tab 内容切换：约 120–160ms，轻淡入/尺寸变化。
- 主题/个人中心全屏路由：约 160–220ms，轻水平 push/crossfade。
- 书架进入阅读：先短暂白色 loading（约 300–450ms）再切正文；无封面 shared-element 动画。
- 选中态颜色：约 100–140ms。

Compose 统一基线：
- route: `tween(190ms, FastOutSlowInEasing)`
- sheet enter: `tween(180ms)` + `fadeIn(120ms)`
- sheet exit: `tween(150ms)` + `fadeOut(100ms)`
- selection: `tween(120ms)`
- 禁止 overshoot/bouncy spring。

## 8. 实现边界

- 视觉与交互尽量按录屏贴近；琅嬛继续使用自己的名称、封面、图标和数据。
- 不连接目标 App 的登录、主题下载、云同步、书源等后端。
- 对应功能在琅嬛有本地等价能力时直接实现；没有等价能力时先实现同位置/同状态模型，再接琅嬛自己的服务。
- 阅读进度、分页、跨章节、正文编辑、AI 创作、故事模式仍复用琅嬛现有稳定数据层。
