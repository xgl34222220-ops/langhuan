# 阅读版纸白墨蓝界面

## 本轮范围

用户批准的五页主体和 B 轻悬浮底栏落地在独立测试分支。书架保持三列、实际封面、排序、分组、长按与进度行为；阅读正文采用此前认可的排版实现，没有改变字体度量、分页或行段距算法。

界面使用局部 `PaperReaderThemeV44`：纸白 `#FAF9F6`、墨蓝 `#15263E`、强调蓝 `#245B9E`，衬线标题、20 dp 页面留白、16–20 dp 纸面卡片。底栏外边距 16 dp，高 64 dp，圆角 20 dp，使用单个小选中块，并计入系统安全区。

- 书架：真实书封三列，弱化非必要装饰，保持开书、搜索、分类、排序和导入
- 书城：搜索框、当前结果来源、发现入口；分类使用三列书封，榜单沿网站实际顺序显示列表；没有来源数据时显示准确空状态
- 书源：搜索、启用数、来自实际规则的能力标签、编辑、删除、导入和导出；没有网络实测结果时不显示“验证通过”
- AI：网站/测试书名、实际配置服务、将验证能力、步骤与结果分组；失败原因完整显示一次，重试保留输入
- 我的：阅读记录、书架管理、本地导入、书源、AI 配置和可收起的旧工具；不虚构云同步、全量备份或下载管理功能

书城分类/榜单分组根据网站声明的入口名称展示；不是平台生成的排行榜。封面缺失时展示书名排印占位，不将示例插画当真实封面。

## 验证

新增 `PaperReaderUiV44DeviceTest` 检查实际配置状态、输入提交和首页错误唯一且可完整阅读；现有设备用例继续覆盖分类、榜单第二页、下载、编辑取消、书架与我的导航。设备截图中的自动化书名、源地址与模型状态均为明确测试夹具，不是线上推荐或真实 AI 调用证据。

本地独立 JVM 网络回归和 UI 契约先验证，完整 Android 编译、lint、单测及设备结果以最终提交对应 CI 为准。应用包名仍为 `com.xiguli.langhuan`；CI 调试签名不等于用户已安装版本签名。
