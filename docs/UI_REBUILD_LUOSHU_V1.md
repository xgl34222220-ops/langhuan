# 琅嬛 UI 重构：洛书母版 V1

## 结论

琅嬛后续 UI 不再以 Qingmo Replica 或 Shadcn New York 作为主视觉基准。**洛书（LuoShu）是琅嬛的母版 UI**。

这不是机械复制洛书页面，而是复用同一套视觉语言，再针对小说产品做结构适配。

## 统一视觉语言

- 页面底色：安静、低对比的浅灰/动态色背景，不铺满高饱和渐变。
- 圆角体系：`7 / 11 / 18 / 24 / 30 dp`。
- 主页面标题：`26/34 sp`，粗体；详情/设置标题使用 `22/28 sp`。
- 通用卡片：默认 `24 dp` 圆角、`1 dp` 轻阴影、`20 dp` 内边距。
- 顶栏操作：`48 dp` 触控区、`44 dp` 可见圆形、`21 dp` 图标。
- 分隔：只使用低对比 `track`，不用可见边框堆层级。
- 液态玻璃：集中用于导航、选中态和悬浮层；普通卡片、图标和正文区保持安静。
- 动效：短、柔和、连续；不为了展示动效打断阅读或页面状态。

## 琅嬛专属适配

### 书架

- 使用原生 cover-first 双列书架，而不是旧 Qingmo Replica 主入口。
- 书封是视觉主角，工具入口退到右上角或“我的”。
- 卡片、弹层、操作按钮统一吃 `LanghuanStableTheme` 和 `LanghuanUiTokens`。

### 阅读器

阅读器正文不是洛书页面的复制对象。以下交互约束优先级高于视觉统一：

1. 切章不得主动唤起系统状态栏。
2. 继续保留 `ReaderWindowSessionV27` 的沉浸会话控制。
3. 正文排版、页眉页脚、分页算法保持阅读优先。
4. 仅将设置 Sheet、Tabs、操作行、按钮等阅读器 Chrome 对齐洛书视觉。
5. UI 重构不得破坏章节进度、翻页、恢复位置和全屏沉浸。

### AI 创作 / 蓝图 / 角色与世界观

- 沿用洛书的大标题、安静卡片、紧凑行项目和悬浮层语言。
- 信息密度可高于洛书，但不能重新引入多套视觉系统。
- 新页面优先复用 `LanghuanUiKit`，不要再创建新的 Replica 组件族。

## 迁移原则

- 活跃入口不得重新指向 `ShelfQingmo*`。
- 旧 Qingmo/Shadcn 文件可暂留作兼容或逐步清理，但不得继续作为新页面的设计标准。
- `LanghuanStableTheme` 是当前实际生效的主题入口，视觉改动优先落这里。
- 新公共组件优先放进 `ui/design/LanghuanUiKit.kt`。
- 阅读器设置类公共组件继续收敛到 `LanghuanComponentKitV4.kt`，直到后续统一命名。
