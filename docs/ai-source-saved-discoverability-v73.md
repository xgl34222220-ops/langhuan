# AI 书源保存后的管理入口（V73）

## 缺口

保存成功状态已经确认精确书源名和事务写入结果，但页面底部的主操作仍首先显示“开始生成”。用户若想立即核对、启停或编辑刚保存的书源，只能回到长页面顶部再使用返回按钮。

## 改进

- 仅在 `aiSavedSourceName != null` 的确认终态显示主操作“返回书源管理查看”。
- 点击沿用现有 `onBack` 路由，返回同一个 ViewModel 驱动的书源管理页；不复制存储、不重新读取或改写书源。
- “开始生成”和“浏览器模式生成”继续作为次操作，网站地址和测试书名保持。
- 不触发取消，不重新生成，不改变保存事务、书源身份、浏览器会话或错误恢复语义。

这遵循 Android UI 事件指南：由按钮点击在 UI 层触发导航，业务写入结果继续由 ViewModel 状态表达。实现保持当前 V3 路由结构，没有引入新的导航框架。

## 回归
